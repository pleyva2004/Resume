# Resume Repository

A collection of resume, CV, and cover letter versions tailored for different roles and opportunities.

## Structure

- **`active/`** - Current versions being used
  - `evolve/` - Resume for Evolve role
  - `research-alignment/` - Resume for research-aligned positions
  
- **`archive/`** - Previous versions organized by semester/role
  - `fall_25/`, `spring/`, `summer-26/` - Seasonal versions
  - `njit-fall-2025/`, `njit-fall-2025-av/`, `njit-fall-2025-short/` - NJIT-specific versions
  - `quant/` - Quantitative finance focused version

- **`cv/`** - Academic curriculum vitae

- **`cover-letters/`** - Cover letters by company
  - `google/` - Google-specific cover letter

## Building

LaTeX files can be compiled to PDF:
```bash
pdflatex <filename>.tex
```

Or use your preferred LaTeX compiler.
